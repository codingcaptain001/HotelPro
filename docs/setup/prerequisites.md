# Prerequisites & System Requirements

## 1. Required Runtimes & Tooling

To run and maintain HotelPro locally or in production, ensure your environment meets the following specifications:

| Component | Minimum Version | Recommended Version | Verification Command |
| :--- | :--- | :--- | :--- |
| **Node.js** | v18.0.0 | v20.x or v22.x LTS | `node -v` |
| **npm** | v9.0.0 | v10.x+ | `npm -v` |
| **Git** | v2.30.0 | Latest stable | `git --version` |
| **MongoDB Atlas** | v6.0+ | MongoDB Atlas Cloud M0+ | [Cloud Atlas Dashboard](https://cloud.mongodb.com/) |

---

## 2. Operating System Compatibility

- **Windows**: Windows 10 / 11 with PowerShell or Command Prompt.
- **macOS**: macOS Monterey (12.0) or higher.
- **Linux**: Ubuntu 20.04+, Debian 11+, Fedora, CentOS, Arch Linux.
